SBPanel de SabriFotos, carpetas y textos del sitio

La clave queda guardada en este navegador, así no hay que ponerla cada vez. Si no la tenés, pedísela a quien armó el sitio.

¿Cómo se consigue la clave?
  1. Entrá a GitHub con la cuenta dueña del sitio y abrí Configuración → Tokens.
  2. Ponele un nombre (por ejemplo "Panel de Sabri") y elegí la duración que quieras.
  3. En Repository access elegí Only select repositories y marcá el repositorio del sitio.
  4. En Permissions → Contents elegí Read and write.
  5. Tocá Generate token, copiá la clave y pegala acá.
